# CodeAlpha Project Video Explanation

## Recommended video length

3 to 5 minutes.

## Recording Script

Hello, my name is Saransh. This is my CodeAlpha C Programming Internship project.

This repository contains four C programming tasks: a basic calculator, matrix operations, a student management system, and a banking system.

First, I will demonstrate the basic calculator. It uses a switch statement to perform addition, subtraction, multiplication, division, and remainder operations. It also validates division by zero.

Next, I will demonstrate the matrix operations program. It uses functions and two-dimensional arrays to perform matrix addition, matrix multiplication, and matrix transpose. The program validates matrix dimensions before calculating a result.

The third task is the Student Management System. It is a menu-driven program that supports adding, displaying, searching, updating, and deleting student records. The records are stored permanently in the students.dat binary data file using C file handling.

The final task is the Banking System mini project. It supports account creation, deposits, withdrawals, balance enquiries, and displaying accounts. Account data is stored permanently in the accounts.dat binary data file. The program also prevents invalid deposits, withdrawals, and withdrawals larger than the available balance.

All programs are written in C using functions, structures, arrays, input validation, and file handling where required. The README file contains the compilation and execution instructions.

Thank you for watching my CodeAlpha project demonstration.

## What to Show on Screen

1. Show the GitHub repository homepage.
2. Open the README and briefly show the task list.
3. Run the calculator and demonstrate one arithmetic operation.
4. Run matrix operations and demonstrate transpose or multiplication.
5. Run the student system and demonstrate add, search, display, update, and delete.
6. Run the banking system and demonstrate account creation, deposit, withdrawal, and balance enquiry.
7. Return to the repository and show the source files, MIT license, and README.

## Upload Steps

1. Record the demonstration using OBS Studio, Windows Snipping Tool, or your phone.
2. Upload the video to YouTube as Unlisted, or upload it to Google Drive.
3. Set the sharing permission to allow anyone with the link to view it.
4. Copy the video URL.
5. Paste the URL into the `Video Explanation Link` section in `README.md`.
6. Commit and push the updated README to GitHub.
7. Submit the GitHub repository link and video link in the CodeAlpha form.
